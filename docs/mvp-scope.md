# Explore PNG MVP Scope

## Business Name
Explore PNG

## Phase 1 Product
Joy Ride Transport

## MVP Goal
A rider can request a ride, a verified driver can accept it, and admin can monitor/control the ride.

## Apps
1. Explore PNG Rider App
2. Explore PNG Driver App
3. Explore PNG Admin App

## MVP v0.1 Features

### Rider App
- Register
- Login
- Request Around Town ride
- Enter pickup location
- Enter destination
- View fare estimate
- Confirm ride
- View driver assigned
- Complete trip
- Rate driver

### Driver App
- Login
- Go online/offline
- Receive ride request
- Accept ride
- Arrive at pickup
- Start trip
- Complete trip

### Admin App
- Login
- View users
- View drivers
- Approve drivers
- View active rides
- View completed rides
- Manually control ride status if needed

## Not Included in MVP v0.1
- Airport pickup
- Hotel transfer
- Scheduled ride
- Group ride
- Promotions
- Payments integration
- Tourism listings
- Events
- Accommodation
- Coffee tours
